## What was verified manually in this build

Run against `npm run build && npm start` in a headless Chromium (Playwright) script and with `curl`:

- Full journey from "Start my analysis": goals → **real PDF upload** (generated by Chromium) and **real DOCX upload** parsed into the editable textarea → pasted resume → 2 JDs → extract and confirm profile → interview answer saved → "Run next steps" to the positioning gate → choose option → run to completion.
- Every workspace page rendered without page errors.
- Editing a headline to "I increased revenue by 45% and hold a PMP certification" was immediately flagged (unsupported 45%, PMP). Re-running QA → **Blocked**; report export returned 409 with an explanation; excluding the statements → **Pass**.
- Version snapshot and comparison page.
- Mobile viewport (390 px): no horizontal page overflow; the stepper scrolls horizontally.
- Settings health check (mock) reports reachable.
- API: another browser session gets 404 for someone else's workspace; invalid action payloads return 400 with a readable message; a fake PDF is rejected with 422; no API key strings in served HTML.

**Not verified:** live Gemini or Groq calls (no API keys in this environment); screen-reader testing with real assistive technology; browsers other than Chromium.

## Manual QA checklist

Use `npm run dev` with `LLM_PROVIDER=mock` unless noted.

### Onboarding and import
- [ ] Home shows the value proposition, privacy note, disclaimer and the current provider mode.
- [ ] "Start my analysis" → Goals; leaving optional fields blank still saves.
- [ ] Upload a PDF, a DOCX and a TXT resume: text appears in the textarea, and nothing is saved until "Save profile text".
- [ ] Upload a `.png` or a renamed fake `.pdf`: a clear error is shown, and pasting still works.
- [ ] The LinkedIn URL field states it is reference only; no network request is made to LinkedIn.
- [ ] Add and remove JDs; a JD containing "Ignore previous instructions…" shows an injection warning.

### Workflow and agents
- [ ] "Run next steps" runs agents one by one (button names the running agent) and stops at: confirm profile, choose positioning, critical QA flags.
- [ ] Each agent card shows its responsibility, status, and "How this insight was produced" (data used, provider/model, latency, attempts; no prompts).
- [ ] Edit a role on Career Profile → re-run discovery → the edit survives (badge "Edited by you").
- [ ] Add a JD after completion → Market and downstream steps show "stale"; "Run next steps" refreshes them.
- [ ] Interview: one question at a time; answer, refresh the page, and the progress is still there; skip works; a brief answer adds one follow-up.

### Evidence integrity
- [ ] Market cards show "n of N"; percentages appear only with 5 or more JDs; the synthetic demo is labelled synthetic everywhere.
- [ ] Gap matrix uses "Not evidenced in supplied material", never "lacks".
- [ ] Every LinkedIn/brand statement shows a status badge and expands to the exact source text.
- [ ] Edit a statement to include a new number or credential → "Needs your confirmation" with a safety note.
- [ ] QA: a critical flag cannot be dismissed; "I can support this" or "Exclude statement" resolves it; the report export is blocked while any critical flag is open.
- [ ] Recruiter Lens is labelled "Simulation".
- [ ] Scores show formulas, "rule-based" labels, "Insufficient data" where applicable, and the "not a probability" caveat.

### Providers (needs keys)
- [ ] `LLM_PROVIDER=gemini` without a key → Settings shows key MISSING; running a step fails with a clear message and a retry button.
- [ ] With a key but without consent → `CONSENT_REQUIRED` message; enabling consent on the Privacy page allows the run.
- [ ] An invalid key → "provider rejected the API key"; quota exhaustion → quota message; data unchanged.
- [ ] Settings → "Check provider health" reports reachability for the configured model.

### Privacy, export, accessibility
- [ ] Report → Download Markdown; Print-friendly HTML opens; Export data (JSON) downloads.
- [ ] Privacy → Delete this analysis → redirected; the analysis is gone from My analyses.
- [ ] Settings → Delete all my data → count shown; list empty.
- [ ] Keyboard-only: all controls reachable, focus ring visible, "Skip to content" link works.
- [ ] Dark mode (OS setting) has readable contrast.
- [ ] Phone width: no horizontal page scroll; stepper scrolls.
